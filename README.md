This project implements and visualizes **Self-Avoiding Random Walks (SARW)** - a fundamental model in statistical physics and computational mathematics where a random walker moves on a lattice with the constraint that it **cannot visit the same site twice**.

Self-avoiding random walks are important in various fields including:
- 🧬 **Polymer physics** - modeling chain molecules
- 🧮 **Statistical mechanics** - studying critical phenomena
- 🖥️ **Algorithm design** - pathfinding and optimization problems
